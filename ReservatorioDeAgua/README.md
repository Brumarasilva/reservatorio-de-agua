# 💡 Sistema de Controle de Eletroválvulas

Este projeto simula o funcionamento de um sistema de controle de duas eletroválvulas (S1 e S2) com base em três condições lógicas fornecidas pelo usuário: A, B e C. A lógica determina se as válvulas devem ser ligadas, desligadas ou se há falha no sistema que exige intervenção técnica.


## $${\color{#ffc1d5}O\space que\space foi\space utilizado?}$$

* Linguagem C#
* Terminal / Console
* VS Code
* ChatGPT (auxílio com explicações)


## $${\color{#ffc1d5}Etapas\space Implementadas:}$$

* Leitura dos três valores (A, B, C) informados pelo usuário.
* Validação da lógica com `if / else if` para cobrir as 8 combinações possíveis.
* Exibição de mensagens específicas para cada cenário.
* Indicação de erro quando as condições indicam falha no sistema.
* Recomendações claras para ligar ou desligar válvulas.

## ${\color{#ffc1d5}{Conclusão:}}$
Este projeto simulou um sistema automatizado de controle de válvulas, permitindo aplicar conhecimentos de lógica condicional em C#. Com base em três condições simples, foi possível implementar uma lógica de decisão clara, útil em ambientes industriais ou educacionais.
